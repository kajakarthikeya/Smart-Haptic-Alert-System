# AI Model Training Subsystem Technical Specification (Phase 5)

## 1. Overview & Objective
The **AI Model Training Subsystem** (`app/ai/training/` and `app/ai/models/`) develops, trains, optimizes, and evaluates a deep 2D Convolutional Neural Network (CNN) environmental sound classification model. It ingests composite acoustic time-frequency matrices generated during Phase 4 (`app/ai/features/dataset_splits.npz`) and learns discriminative representations to classify five critical target environmental sounds for hearing-impaired users.

---

## 2. Target Sound Classes
The model performs multi-class classification across exactly five target environmental sounds:
1. **Ambulance** (Class ID: `0`)
2. **Car Horn** (Class ID: `1`)
3. **Fire Alarm** (Class ID: `2`)
4. **Doorbell** (Class ID: `3`)
5. **Dog Bark** (Class ID: `4`)

Bidirectional class string and ID mappings are managed via `app/ai/features/class_names.json`.

---

## 3. Input Feature Specification
- **Representation**: Composite 2D time-frequency matrix generated by Librosa feature extractor.
- **Matrix Dimensions**: `(184, 173)`
  - **Frequency/Spectral Dimension (184 rows)**:
    - Mel Spectrogram (128 rows, dB scale)
    - MFCC (40 rows)
    - Zero Crossing Rate (1 row)
    - Spectral Centroid (1 row)
    - Spectral Bandwidth (1 row)
    - Spectral Rolloff (1 row)
    - Chroma STFT (12 rows)
  - **Time Frames Dimension (173 columns)**: 4.0-second audio clips sampled at 22,050 Hz with `n_fft=2048`, `hop_length=512`.
- **CNN Input Tensor Shape**: `(batch_size, 184, 173, 1)` with channel dimension expanded for 2D spatial convolution.

---

## 4. Deep Learning Architecture (`CNNSoundClassifier`)
The model employs a hierarchical 2D Convolutional Neural Network architecture designed for audio spectrogram processing:

```
[Input Layer] (184, 173, 1)
      │
[Conv Block 1] Conv2D (32 filters, 3x3, same) ➔ BatchNorm ➔ ReLU ➔ MaxPool2D (2x2) ➔ Dropout (0.25)
      │
[Conv Block 2] Conv2D (64 filters, 3x3, same) ➔ BatchNorm ➔ ReLU ➔ MaxPool2D (2x2) ➔ Dropout (0.25)
      │
[Conv Block 3] Conv2D (128 filters, 3x3, same) ➔ BatchNorm ➔ ReLU ➔ MaxPool2D (2x2) ➔ Dropout (0.30)
      │
[Global Avg Pooling] GlobalAveragePooling2D
      │
[Dense Head] Dense (128 units) ➔ BatchNorm ➔ ReLU ➔ Dropout (0.50)
      │
[Output Layer] Dense (5 units, Softmax) ➔ Output Probabilities
```

- **Total Trainable Parameters**: 111,237 parameters.
- **Regularization**: Batch Normalization, spatial Dropout, Global Average Pooling, and weight decay.

---

## 5. Training Strategy & Optimization

### Optimization Parameters
- **Optimizer**: Adam ($\beta_1=0.9, \beta_2=0.999$)
- **Learning Rate**: Initial $\eta = 0.001$, dynamically modulated by learning rate scheduler.
- **Loss Function**: Sparse Categorical Crossentropy ($L = -\sum_{c} y_c \log \hat{y}_c$).
- **Batch Size**: 4 (balanced for small-to-medium dataset splits).
- **Epochs**: 50 max epochs with early stopping patience of 15.

### Callbacks & Regularization
1. **ModelCheckpoint**: Monitors `val_accuracy`, automatically persisting the highest-performing checkpoint to `app/ai/models/sound_classifier_best.keras`.
2. **EarlyStopping**: Monitors `val_loss` with patience=15, restoring best model weights upon plateau.
3. **ReduceLROnPlateau**: Halves learning rate ($\text{factor}=0.5$) if validation loss stagnates for 7 consecutive epochs.
4. **Balanced Class Weighting**: Adjusts loss penalties to prevent majority-class bias using:
   $$w_c = \frac{N_{total}}{K \cdot n_c}$$

## 7. Subsystem Integration & Handshakes
- **Upstream (Phase 4)**: Consumes `app/ai/features/dataset_splits.npz`, `class_names.json`, and `scaler_params.json`.
- **Downstream (Phase 6 - Model Evaluation)**: Delivers `sound_classifier_best.keras`, test splits, and metadata for confusion matrices, precision/recall/F1 metrics, and latency benchmarking.
- **Downstream (Phase 7 - Real-Time Recognition)**: Delivers weights for live microphone streaming inference via `SoundInferenceEngine`.
